# herdr-relay

A WebSocket relay for monitoring and approving [herdr](https://herdr.dev) AI
agents from your phone. It polls herdr for agent state, accepts pushed events,
and broadcasts them to connected clients — which send approvals and terminal
input back through the same socket.

Its reason to exist is [herdr-mobile](https://github.com/sbulav/herdr-mobile),
the Android client. A single-file web PWA and a Telegram bot also speak the
protocol.

> Originally forked from [dcolinmorgan/herdr-remote](https://github.com/dcolinmorgan/herdr-remote)
> (AGPL-3.0-or-later — see [`LICENSE`](LICENSE)). It is now a hard fork with its
> own protocol contract and no upstream merge target.

## What it does

- **Live agent state** — who is working, who is blocked, who finished
- **One-tap approvals** — answer a blocked agent's prompt from your phone
- **Terminal interaction** — read pane output, send keys, send text, interrupt
- **Attention metadata** — the relay decides `waiting`/`working`/`done`/`idle`
  and stamps `updated_at` and `output_revision`, so clients don't infer it from
  status strings
- **Multi-host** — polls local herdr plus any SSH targets in `HERDR_REMOTES`
- **Push and poll** — authenticated HTTP events beat the poll interval
- **Host readiness** — separates SSH reachability, Herdr readiness, and active-agent count
- **Saved projects** — host-scoped SQLite bookmarks with safe lazy folder browsing, labels, search, and non-destructive archive/restore

## Run it

The Python scripts carry [PEP 723](https://peps.python.org/pep-0723/) inline
metadata, so `uv run` installs dependencies itself.

```bash
export HERDR_RELAY_TOKEN="$(openssl rand -hex 16)"   # required
uv run relay/herdr-relay.py
```

For a real host, `nix run github:sbulav/herdr-relay` or the NixOS module — see
[`docs/deployment.md`](docs/deployment.md), which is also where the reverse-proxy
requirements live.

```bash
HERDR_TG_TOKEN="..." HERDR_TG_CHAT_ID="..." uv run relay/herdr_telegram.py
```

| Telegram command | Action |
|---------|--------|
| `/agents` | List all with status |
| `/read` | Read agent output |
| `/reply` | Read + respond in one flow |
| `/send` | Send text to an agent |
| `/trust` | Trust all tools for a blocked agent |
| `/interrupt` | Send Ctrl+C |
| `/digest` | Today's activity summary |

## Configuration

| Variable | Purpose |
|----------|---------|
| `HERDR_RELAY_TOKEN` | Shared secret. **Required** — the relay refuses to start without it |
| `HERDR_RELAY_PORT` | WebSocket port (default: 8375) |
| `HERDR_REMOTES` | Comma-separated SSH targets to poll |
| `HERDR_HOSTS_FILE` | Versioned host configuration with public names, private routing, roots, wrappers, harnesses, power capabilities, and readiness timeouts |
| `HERDR_PROJECTS_DB` | Writable SQLite path for saved host-scoped projects (default: `~/.local/state/herdr-relay/projects.sqlite3`) |
| `HERDR_BIN` | Path to the herdr binary (default: `/opt/homebrew/bin/herdr`) |

Every variable the relay reads is tabulated in
[`docs/deployment.md`](docs/deployment.md).

Optional push acceleration, from any machine running herdr:

```bash
herdr plugin install dcolinmorgan/herdr-push
export HERDR_RELAY="https://relay.example.com"
```

## Architecture

```
herdr-mobile (Android)   web PWA   Telegram bot
         └───────── WebSocket ─────────┘
                       │
              relay (:8375)  ←── reverse proxy (public wss://)
                       │
         ┌─────────────┴─────────────┐
    poll herdr CLI            pushed events
    (local + SSH)             (HTTP, same port)
```

Server-side state stays server-side: the SSH target behind a host, and a
preset's `target`, are never broadcast. A client addresses a pane by `host` and
`pane_id`.

## Host power controls

The relay accepts typed `wake_host` and `shutdown_host` operations for hosts
whose private host configuration enables those capabilities. Wake runs
`wakeonlan` locally; shutdown uses the private SSH target and the fixed command
`sudo -n systemctl poweroff`. The relay never accepts shell text from a client.
See `contract/host-config-v1.schema.json` for the versioned configuration shape.

Project operations are also typed. `project_browse` accepts only an opaque root
handle and relative path components; the fixed host helper uses descriptor-relative
no-follow traversal. `project_create` atomically creates exactly one validated
empty child and registers it with durable request replay. `project_save`,
`project_rename`, `project_remove`, and `project_restore` write only relay metadata.
Removing a bookmark never touches its directory, and configuration changes mark old
rows unavailable instead of deleting them.

## Develop

```bash
make check     # ruff + unittest
```

Changing a wire frame means regenerating the goldens, then syncing them into
herdr-mobile's `protocol-fixtures/native/`:

```bash
UPDATE_CONTRACT=1 make test
```

## Requirements

- Python 3.10+ with [uv](https://docs.astral.sh/uv/), or Nix
- herdr 0.7+
- A TLS-terminating reverse proxy, for access from outside the LAN —
  [`docs/deployment.md`](docs/deployment.md) says what it has to do
