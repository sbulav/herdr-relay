# herdr-relay

A WebSocket relay for monitoring and approving [herdr](https://herdr.dev) AI
agents from your phone. It polls herdr for agent state, accepts pushed events,
and broadcasts them to connected clients — which send approvals and terminal
input back through the same socket.

Its reason to exist is [herdr-mobile](https://github.com/sbulav/herdr-mobile),
the Android client. A single-file web PWA and a Telegram bot also speak the
protocol.

> Originally forked from [dcolinmorgan/herdr-remote](https://github.com/dcolinmorgan/herdr-remote)
> (AGPL-3.0-or-later — see [`LICENSE`](LICENSE)). It is now a hard fork with its
> own protocol contract and no upstream merge target.

## What it does

- **Live agent state** — who is working, who is blocked, who finished
- **One-tap approvals** — answer a blocked agent's prompt from your phone
- **Terminal interaction** — read pane output, send keys, send text, interrupt
- **Attention metadata** — the relay decides `waiting`/`working`/`done`/`idle`
  and stamps `updated_at` and `output_revision`, so clients don't infer it from
  status strings
- **Multi-host** — polls local herdr plus any SSH targets in `HERDR_REMOTES`
- **Push and poll** — HTTP POST and UDP events beat the poll interval

## Components

| Path | What |
|------|------|
| `relay/herdr_relay.py` | The relay: WebSocket + HTTP server, host polling |
| `relay/herdr_telegram.py` | Telegram bot client |
| `web/index.html` | Single-file web PWA (browser client) |
| `docs/native-protocol.md` | **The wire contract.** Clients are written against it |
| `contract/native/` | Golden frames, generated by the relay, asserted by both repos |

## Run it

The Python scripts carry [PEP 723](https://peps.python.org/pep-0723/) inline
metadata, so `uv run` installs dependencies itself.

```bash
export HERDR_RELAY_TOKEN="$(openssl rand -hex 16)"   # required
uv run relay/herdr_relay.py
```

`relay/start.sh` does the same and opens a Cloudflare tunnel, giving you a
public `wss://` URL to paste into a client.

```bash
HERDI_TG_TOKEN="..." HERDI_TG_CHAT_ID="..." uv run relay/herdr_telegram.py
```

| Telegram command | Action |
|---------|--------|
| `/agents` | List all with status |
| `/read` | Read agent output |
| `/reply` | Read + respond in one flow |
| `/send` | Send text to an agent |
| `/trust` | Trust all tools for a blocked agent |
| `/interrupt` | Send Ctrl+C |
| `/digest` | Today's activity summary |

## Configuration

| Variable | Purpose |
|----------|---------|
| `HERDR_RELAY_TOKEN` | Shared secret. **Required** — the relay refuses to start without it |
| `HERDR_RELAY_PORT` | WebSocket port (default: 8375) |
| `HERDR_REMOTES` | Comma-separated SSH targets to poll |
| `HERDR_BIN` | Path to the herdr binary (default: `/opt/homebrew/bin/herdr`) |

Optional push acceleration, from any machine running herdr:

```bash
herdr plugin install dcolinmorgan/herdr-push
export HERDR_RELAY="https://your-tunnel.trycloudflare.com"
```

## Architecture

```
herdr-mobile (Android)   web PWA   Telegram bot
         └───────── WebSocket ─────────┘
                       │
              relay (:8375)  ←── Cloudflare tunnel (public wss://)
                       │
         ┌─────────────┴─────────────┐
    poll herdr CLI            pushed events
    (local + SSH)             (HTTP POST / UDP)
```

Server-side state stays server-side: the SSH target behind a host, and a
preset's `target`, are never broadcast. A client addresses a pane by `host` and
`pane_id`.

## Host power controls

The relay accepts typed `wake_host` and `shutdown_host` operations when
`HERDR_POWER_HOST_ID` and `HERDR_POWER_HOST_MAC` are configured. Wake runs
`wakeonlan` locally; shutdown uses the configured preset's SSH target and the
fixed command `sudo -n systemctl poweroff`. The relay never accepts shell text
from a client.

## Develop

```bash
make check     # ruff + unittest
```

Changing a wire frame means regenerating the goldens, then syncing them into
herdr-mobile's `protocol-fixtures/native/`:

```bash
UPDATE_CONTRACT=1 make test
```

## Requirements

- Python 3.10+ with [uv](https://docs.astral.sh/uv/)
- herdr 0.7+
- `cloudflared`, for remote access
